# Beautiro 인도네시아 릴스 — 첫 문의 유도용

## 제작물
- MP4: 1080 × 1920, 9:16, 30fps, H.264, 20초.
- 세란플러스 공식 시설 사진을 활용한 모션 슬라이드 영상. 실제 촬영 영상이나 AI 생성 병원 영상이 아님.
- 무음 마스터: 업로드할 때 Instagram에서 상업적 사용이 가능한 잔잔한 음원을 선택. 인도네시아어 자막으로 무음 시청 가능.
- 사진 출처: http://seranplus.co.kr/page/sub01_04.php (lobby6, lobby8, lobby10).

## 추천 길이와 구성
첫 편은 20초로 시작한다. 최적 길이가 확정된 수치는 아니며, 브랜드 설명과 문의 행동을 담기 위한 제작 제안이다.

- 0–4초: “한국에서 미용 관리를 고민하시나요?” 관심 주제 제시.
- 4–9초: 실제 병원과 직접 조율하는 운영 방식.
- 9–14초: 픽업·통역·병원 프로모션 안내. 무료·할인율을 일괄 보장하지 않는다.
- 14–20초: 비용·일정을 WhatsApp으로 질문하도록 안내.

3. 고정 댓글: “Ketik KOREA di DM untuk mulai konsultasi. Link WhatsApp ada di bio.”
4. 문의 응답 시 관심 시술과 방문 희망 월부터 확인한다. 고객에게 필요한 안내를 순서대로 제공한다.
5. 이 릴스에서 들어온 문의는 Instagram Reels 유입으로 기록한다.

## 후속 콘텐츠
- 두 번째 릴스: “한국 의료 여행, 어디서부터 시작할까요?” 상담 → 병원 조율 → 픽업·통역의 실제 절차.
- 세 번째 릴스: “세란플러스에서 어떤 진료를 상담할 수 있나요?” 피부·리프팅 등 실제 목록과 문의 안내. 사용 가능 시술·가격은 병원 확인 기준으로 안내.
- 사진 슬라이드 다음에는 직원이 스마트폰으로 촬영한 로비·상담실·차량 동선의 짧은 클립을 활용하면 현장감을 더할 수 있다.

## 성과 판단
조회 수만으로 판단하지 않는다. 프로필 방문, 실제 WhatsApp/DM 문의, 시술·방문 일정이 구체적인 상담, 예약 요청 수를 함께 본다. 유료 광고는 문의로 이어지는 소재를 확인한 뒤 별도 예산을 정해 진행한다. 이번 작업에는 게시나 광고 집행이 포함되지 않는다.
